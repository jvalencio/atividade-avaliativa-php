# Atividade Avaliativa PHP

Atividade avaliativa desenvolvida para a faculdade com o objetivo de praticar os conceitos básicos de **Programação Orientada a Objetos (POO) em PHP**.

## Sobre o Projeto

O projeto consiste na implementação de duas classes principais:

* **Funcionário** — representa os funcionários da empresa.
* **Departamento** — representa os departamentos aos quais os funcionários estão relacionados.

A interação entre as classes é realizada no arquivo `test.php`, utilizado para instanciar os objetos e testar seu funcionamento.

## Tecnologias

* PHP 8.5

## Estrutura

```text
├── Funcionario.php
├── Departamento.php
├── teste.php
└── README.md
```

## Objetivo

Projeto desenvolvido exclusivamente para fins acadêmicos, como parte de uma atividade avaliativa da faculdade.
